# primavera_p6

Primavera P6 PDS Table Selector and Reporting View Metadata Tool.

## Getting Started

1. Copy `.env.example` to `.env` and configure your PDS credentials and endpoint:
   ```bash
   cp .env.example .env
   ```
2. Run the application:
   ```bash
   python pds_table_selector.py
   ```
3. Access the web interface at `http://localhost:8765`.
